### 2. The AI Research Agent Needs a Scientific Method


The HTTP Terminator work deserves a second, distinct treatment. Kettle describes a system where autonomous research works because **evaluation is unusually cheap and objective**: an HTTP response either exhibits the hypothesised parsing discrepancy or it doesn't. Generative ideation can therefore be noisy because an automated experiment filters the noise. 

**Angle:** Generalise beyond security.

Agentic systems become dramatically more useful where you can construct a tight:

`hypothesis → experiment → measurement → rejection → mutation`

loop.

Coding has tests. Security research has exploitability. Electronics has simulation and measurement. Infrastructure has deployment plus telemetry. Many business-agent applications have nothing comparably objective — which may explain why they plateau much sooner.

This would dovetail particularly nicely with the idea of **tests as the real source of agent reliability**, rather than increasingly elaborate prompts.
