## 5) eBPF Is Quietly Becoming Linux's Security Substrate


**Suggested title:** *The Kernel Has Gained a Programmable Immune System*

**Summary:**  
As kernel vulnerabilities continue to surface, eBPF is increasingly being used for runtime telemetry, behavioural detection, networking, and policy enforcement. The trend suggests a move away from static signatures toward programmable runtime defence.

**Angle:**  
Position eBPF as the security equivalent of what virtualisation became for compute.
