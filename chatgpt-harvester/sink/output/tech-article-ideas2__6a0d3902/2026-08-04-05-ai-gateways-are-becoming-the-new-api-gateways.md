## 5) AI Gateways Are Becoming the New API Gateways


**Suggested title:** *Every Enterprise AI Deployment Is Building a Control Plane*

**Summary**  
Citrix has added MCP Gateway functionality to its NetScaler AI Gateway, combining routing, governance, authentication, and observability for agent traffic. This is a strong indicator that AI gateways are becoming their own infrastructure category. 

**Angle**

Compare this evolution to API gateways and service meshes: once a protocol stabilises, operational tooling becomes the differentiator.
