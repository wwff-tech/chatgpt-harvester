## 5) Ubuntu Is Raising the Security Baseline Instead of Adding More Features


**Suggested title:** *Security Wins by Raising the Floor, Not Raising the Ceiling*

**Summary:**  
Ubuntu 26.04 LTS places greater emphasis on secure defaults, confidential computing support, post-quantum-aware cryptography, memory-safe replacements, and stricter TLS policies. It's a good example of improving systemic security rather than relying on individual hardening steps. 

**Angle**

Explore the idea that secure defaults consistently outperform optional security features.
