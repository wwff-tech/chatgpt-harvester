### 10. Left-field — “Machine-Readable Reality Is More Valuable Than Another AI Model”


The USBridge project accidentally illustrates something broader about useful AI infrastructure. Its cleverest contribution isn't putting an LLM near a BIOS; it's transforming an opaque visual interface into **structured, deterministic, low-bandwidth state** first. 

**Angle:** Agent projects frequently start with:

`give model screenshot → ask model what to do`.

A stronger architecture is often:

`world → deterministic parser/sensor → structured state → model → constrained action`.

Examples:

`BIOS pixels → text`

`webpage → DOM`

`network → flow records`

`infrastructure → resource graph`

`source tree → AST`

`electronics → instrument readings`.

The model should receive the **best representation engineering can cheaply provide**, rather than being paid tokens to rediscover structure from raw sensory input every time.

That gives you a useful maxim:

**Use AI for ambiguity; use software for structure.**
