### 2. **“A Security Benchmark Became Obsolete the Moment the Model Scored 100%”** — Short / medium post


Astra scored **100% on ExploitBench**, a benchmark based on exploiting known vulnerabilities. OpenAI was sufficiently concerned about contamination and ceiling effects that it built a newer internal benchmark from 20 recently disclosed V8 vulnerabilities; Astra still substantially outperformed GPT-5.6 Sol there, while using fewer output tokens. 

**Angle:** Benchmarks don't merely tell us how good systems are.

They have a **useful dynamic range**.

Once:

`best systems → 100%`

the benchmark no longer measures progress at the frontier.

Worse, popular benchmarks gradually become part of:

`training data`

`examples`

`fine-tuning`

`agent skills`

`evaluation-aware optimisation`.

So frontier evaluation needs something closer to security red-teaming:

`continually refreshed`

`partly private`

`recent`

`adversarial`

`expensive to memorise`.

There is a broader lesson for coding-agent benchmarks too:

> **A benchmark is infrastructure with a half-life.**
