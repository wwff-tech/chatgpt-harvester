## 3) The Linux Security Story SREs Should Care About


- **Title:** *Privilege Escalation Is Becoming a Cloud-Native Problem*
- **Summary:** Copy Fail affects major distributions and can enable container escapes and root escalation across Kubernetes and CI environments. Active exploitation has already been reported. 
- **Angle:** Analyse the issue from an operational resilience perspective rather than a vulnerability perspective.
- **Matches Interests:** SRE, Kubernetes, Linux, cloud security
- **Format:** **Long form**

**Suggested Points**
- Shared-kernel risk
- Container isolation assumptions
- CI runner exposure
- Patch prioritisation
- Mitigation beyond patching
