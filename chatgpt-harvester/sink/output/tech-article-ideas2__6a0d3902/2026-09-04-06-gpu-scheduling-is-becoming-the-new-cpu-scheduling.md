## 6. GPU Scheduling Is Becoming the New CPU Scheduling


AI platforms increasingly optimise:

- VRAM
- PCIe topology
- accelerator availability
- model locality
- power budget

rather than simply CPU utilisation. 

**Angle**

Twenty years ago:

```
CPU scheduler
```

became sophisticated.

Now:

```
GPU scheduler
```

is following the same path.

Infrastructure complexity hasn't disappeared.

It has migrated.
