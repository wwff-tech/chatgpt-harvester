## 1) The New Security Bottleneck Isn't Finding Bugs


**Suggested title:** *AI Made Vulnerability Discovery Cheap. Now What?*

**Summary:**  
The disclosure of the 15-year-old **GhostLock** Linux kernel vulnerability continues to resonate because it was uncovered using AI-assisted analysis and affects virtually every major distribution. The bigger story is that code review economics have fundamentally changed. 

**Angle**

Treat this as an economics story, not an AI story. Discovery is becoming inexpensive; validation, testing, prioritisation, and deployment remain expensive.
