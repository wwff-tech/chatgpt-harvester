## 3) AI Agent Supply Chains Need the Same Discipline as CI/CD


**Suggested title:** *Dependency Cooldowns Shouldn't Stop at Python Packages*

**Summary:**  
Security researchers are increasingly recommending "dependency cooldowns" for AI coding agents, while recent incidents include compromised AI tooling and credential exposure during agent workflows. The pattern mirrors lessons learned from traditional software supply-chain security. 

**Angle:**  
Treat AI toolchains like production CI/CD pipelines, with provenance, staged rollout, and trust policies.

**Matches your interests:** DevSecOps, AI engineering, Python, supply-chain security

**Format:** **Long-form article**

**Suggested points**
- Cooldown windows
- Sigstore and provenance
- Tool pinning
- Human approval gates
- Trust scoring
