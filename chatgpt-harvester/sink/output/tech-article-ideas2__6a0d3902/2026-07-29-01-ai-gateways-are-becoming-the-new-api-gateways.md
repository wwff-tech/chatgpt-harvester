## 1) AI Gateways Are Becoming the New API Gateways


**Suggested title:** *Every Enterprise AI Deployment Is Rebuilding the API Gateway*

**Summary:**  
Citrix has added MCP Gateway capabilities to its AI Gateway, bringing authentication, policy enforcement, routing, and observability for Model Context Protocol traffic into a single control plane. This is a strong indicator that AI gateways are becoming a distinct infrastructure category. 

**Angle:**  
Draw parallels with the rise of API gateways and service meshes. Once a protocol standardises, the operational tooling becomes the differentiator.

**Matches your interests:** AI infrastructure, platform engineering, cloud architecture, distributed systems

**Format:** **Long-form article**

**Suggested points**
- Why direct agent-to-tool access doesn't scale
- Identity before prompts
- Observability for AI traffic
- Policy enforcement
- Predictions for an "AI control plane"
