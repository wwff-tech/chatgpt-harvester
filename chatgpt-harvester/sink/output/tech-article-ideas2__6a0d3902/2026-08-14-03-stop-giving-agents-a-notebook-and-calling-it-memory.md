### 3. Stop Giving Agents a Notebook and Calling It Memory


The same research found little behavioural improvement from lightweight text-based “cognitive scaffolding” tools that let agents record intermediate thoughts, while changes to actionable tool architecture produced substantial effects. 

**Angle:** A scratchpad is not necessarily useful state.

Useful agent state may look much more like ordinary application state:

`facts`

`decisions`

`unresolved questions`

`tested hypotheses`

`failed approaches`

`artefact references`

rather than a transcript of what the model previously thought.

This makes agent memory less like journalling and more like **database schema design**.
