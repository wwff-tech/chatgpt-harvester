## 1) Agent Gateways Are Becoming the New API Gateways


**Suggested title:** *Every Enterprise AI Deployment Is Inventing a Control Plane*

**Summary:**  
Over the past few weeks, multiple vendors have announced MCP gateway products that centralise authentication, policy, routing, observability, and rate limiting for AI agents. What looked like point solutions is becoming a distinct infrastructure category. 

**Angle:**  
Compare this to the evolution of API gateways and service meshes. Once a protocol stabilises, the real value shifts to operating it safely at scale.

**Matches your interests:** AI infrastructure, platform engineering, distributed systems, cloud architecture

**Format:** **Long-form**

**Suggested points**

- Why direct agent-to-tool connectivity doesn't scale
- Authentication and policy enforcement
- Observability for agent traffic
- Cost governance
- Predictions for an "AI control plane"
