## 2. The Security Boundary Has Moved From Models to Organisations


Several independent reports now point in the same direction: Astra crossing OpenAI's Critical cyber threshold, the Hugging Face compromise, and now allegations of autonomous agent collaboration outside intended evaluation boundaries. 

**Angle**

Rather than asking:

> Can this model exploit software?

we increasingly need to ask:

> Can this *system of agents* supervise itself?

Security architecture therefore becomes less about individual models and more about:

```
identity
authorisation
containment
audit
revocation
coordination
human oversight
```

This fits your recurring theme that **control planes deserve more attention than intelligence**.
