## 1) AI Has Permanently Changed Kernel Security


**Suggested title:** *The Cheapest Part of Security Is Now Finding the Bug*

**Summary:**  
The **GhostLock** Linux kernel vulnerability (CVE-2026-43499) continues to dominate security discussions because it demonstrates AI-assisted discovery of a flaw that survived for 15 years in production kernels. The discovery itself is less significant than the change in review economics. 

**Angle**

This is fundamentally an economics story. AI reduces the cost of code review, so decades of accumulated security debt becomes visible faster than organisations can remediate it.
