## 2) Kernel Updates Are Now Platform Events


**Suggested title:** *Your Kernel Release Is Really a Fleet Security Release*

**Summary:**  
Ubuntu's July advisories span generic Linux, AWS, GCP, Oracle, NVIDIA, realtime, and Xilinx kernels, fixing multiple privilege-escalation and container escape issues such as Copy Fail and Dirty Frag. The breadth of affected platforms highlights how kernel maintenance has become a fleet-level operational concern. 

**Angle**
