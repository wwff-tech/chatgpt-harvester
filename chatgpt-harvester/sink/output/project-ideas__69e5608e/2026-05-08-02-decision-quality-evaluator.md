# 2. Decision Quality Evaluator


**Problem**  
Systems make thousands of decisions, but rarely evaluate if those decisions were *correct* or *optimal*.

**Approaches**
- Compare decisions against outcomes  
- Define success metrics per decision type  
- Identify systematic decision errors  

**Tech hints**
- Outcome labelling pipelines  
- Feedback loops (supervised + RL-style)  
- Statistical evaluation of decisions vs results  

**Formats**
- Dashboard  
- Offline analysis tool  
- CI/CD decision tests  

**Why good fit**
- Brings accountability to automation  
- Strong alignment with AI eval trends  

**Why not**
- Attribution is difficult (multi-causal systems)  
- Requires clean outcome data  

**Revenue potential**  
High  

**Content potential**  
Very high  

**Community potential**  
Medium → High
