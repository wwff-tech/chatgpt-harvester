# 4. Security Event Provenance Graph


**Problem**  
Security incidents are analysed as discrete events rather than full causal chains.

**Approaches**
- Build graph of events leading to incidents  
- Identify root causes and propagation paths  
- Enable replay and simulation  

**Tech hints**
- Graph databases  
- Integration with SIEM tools  
- Mapping to frameworks like MITRE ATT&CK  

**Formats**
- Security dashboard  
- Forensics tool  
- Investigation CLI  

**Why good fit**
- Strong security demand  
- Useful for audits and compliance  

**Why not**
- High data ingestion requirements  
- Complex modelling  

**Revenue potential**  
High  

**Content potential**  
High  

**Community potential**  
Medium
