## 6. “Context Boundary Detector”


**Problem**  
Context from one domain (task, system, conversation) leaks into another, causing errors and misaligned decisions.

**Approaches**
- Detect context mixing across domains  
- Isolate and reset context when needed  
- Provide visibility into context boundaries  

**Tech hints**
- Context tagging  
- Session isolation  
- Heuristic detection of drift  

**Formats**
- Agent middleware  
- CLI tool  
- Personal productivity assistant  

**Why good fit**
- Applies to both AI systems and human cognition  
- Subtle but high-impact issue  

**Why not**
- Hard to detect reliably  
- Requires structured context  

**Revenue potential**
- Medium  

**Content potential**
- Very high  

**Community potential**
- Medium
