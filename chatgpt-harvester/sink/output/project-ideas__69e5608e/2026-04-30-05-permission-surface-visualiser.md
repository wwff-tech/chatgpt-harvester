## 5. “Permission Surface Visualiser”


**Problem**  
Permissions accumulate across systems, creating large, poorly understood attack surfaces.

**Approaches**
- Map permissions across users, services, and systems  
- Visualise relationships and inheritance  
- Highlight over-privileged entities  

**Tech hints**
- Graph databases (Neo4j)  
- IAM API integrations  
- Risk scoring heuristics  

**Formats**
- Web dashboard  
- CLI audit tool  
- Security report generator  

**Why good fit**
- Strong security relevance  
- High practical value  

**Why not**
- Requires deep integration  
- Complex data modelling  

**Revenue potential**
- High  

**Content potential**
- High  

**Community potential**
- Medium → High
