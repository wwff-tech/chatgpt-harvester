## 7. Leftfield: “Home Energy Event Stream + Optimiser”


**Problem**  
Home energy usage (especially with solar, EVs) is poorly optimised and lacks real-time decision systems.

**Approaches**
- Event stream from smart meter + devices
- Rule engine for optimisation (run dishwasher at X, charge at Y)
- Predictive model based on usage patterns

**Tech hints**
- MQTT broker
- Python + Pandas
- Time-series DB (InfluxDB)
- ESP32 integrations

**Formats**
- Local server + dashboard
- Home Assistant integration
- Mobile alerts

**Why good fit**
- Hardware + software crossover (you enjoy this)
- Real-world measurable impact

**Why not**
- Hardware integration friction
- Limited audience unless generalised

**Revenue potential**
- Medium

**Content potential**
- High (practical + technical)

**Community potential**
- Medium → High (home automation crowd)
