# 6. Harness Attribution Engine


## Problem Statement

Research increasingly suggests that harnesses matter more than prompts for sustained agent performance. 

Teams struggle to answer:

> Which harness component actually improved results?

## Approaches

### Approach A

Track every harness modification.

Require predicted outcomes before deployment.

Measure actual outcomes afterwards.

### Approach B

Build attribution graphs connecting:

- middleware,
- tools,
- memory,
- prompts,
- evaluation metrics.
