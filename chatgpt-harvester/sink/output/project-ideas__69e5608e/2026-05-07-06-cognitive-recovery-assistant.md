# 6. “Cognitive Recovery Assistant”


**Problem**  
After interruptions, humans struggle to regain context and momentum.

**Approaches**
- Detect interruption events  
- Provide structured “resume context”  
- Suggest next actions  

**Tech hints**
- Activity tracking  
- Context snapshots  
- Lightweight summarisation  

**Formats**
- Desktop app  
- IDE plugin  
- CLI tool  

**Why good fit**
- Strong ADHD/ASD relevance  
- Immediate personal utility  

**Why not**
- Requires behavioural adoption  
- Context capture overhead  

**Revenue potential**
Medium  

**Content potential**
Very high  

**Community potential**
High

`adhd`, `focus`, `recovery`, `productivity`, `context`
