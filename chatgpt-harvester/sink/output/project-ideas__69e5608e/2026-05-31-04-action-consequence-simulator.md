# 4. Action Consequence Simulator


## Problem Statement

Action-oriented agents now dominate MCP usage growth. 

Most systems can answer:

> Can the agent do this?

Few can answer:

> What happens if it does?

## Approaches

### Approach A

Build blast-radius simulations before execution.

Model:

- affected systems,
- permissions,
- downstream dependencies.

### Approach B

Generate probabilistic consequence graphs.

Estimate likely operational outcomes.

## Suggested Tech Hints

- Dependency graphs
