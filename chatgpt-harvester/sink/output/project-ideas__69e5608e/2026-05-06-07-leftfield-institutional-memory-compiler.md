# 7. Leftfield: “Institutional Memory Compiler”


**Problem**  
Organisations repeatedly lose operational knowledge:
- incidents,
- migrations,
- political context,
- architectural rationale,
- tribal knowledge.

AI accelerates knowledge generation, but also accelerates forgetting.

### Approaches
- Convert operational history into structured memory
- Build searchable rationale graphs
- Generate “why the system exists this way” summaries

### Tech hints
- Knowledge graphs
- Semantic indexing
- Temporal linking
- Provenance tracking

### Formats
- Internal wiki augmentation
- CLI knowledge tool
- Architecture memory system

### Why it is a good fit
- Massive hidden enterprise pain point
- Strong overlap with SRE culture
- Useful beyond engineering

### Why it is not a good fit
- Requires cultural adoption
- Sensitive organisational data

### Revenue potential
High

### Content tie-in potential
Very high
