# 6. “Cognitive Confidence Tracker”


**Problem**  
People misjudge their own confidence, leading to poor decisions, especially under cognitive load.

**Approaches**
- Track confidence vs outcomes  
- Identify overconfidence/underconfidence patterns  
- Provide feedback loops  

**Tech hints**
- Journaling + outcome tracking  
- Statistical calibration analysis  
- Visual dashboards  

**Formats**
- Mobile/desktop app  
- CLI tool  
- Weekly reports  

**Why good fit**
- Strong ADHD/ASD relevance  
- High personal insight value  

**Why not**
- Requires consistent input  
- Behavioural resistance  

**Revenue potential**  
Medium  

**Content potential**  
Very high  

**Community potential**  
High

`confidence`, `self-awareness`, `adhd`, `decision-making`
