## 7. Leftfield: “Toolchain Entropy Tracker”


**Problem**  
Developer environments accumulate tools, configs, and dependencies, increasing complexity (“entropy”) over time.

**Approaches**
- Track installed tools, versions, configs
- Measure change frequency + inconsistency
- Provide “entropy score” + cleanup suggestions

**Tech hints**
- System introspection scripts
- Package manager APIs (apt, brew, pip)
- Simple scoring model

**Formats**
- CLI tool
- Periodic report generator
- Optional dashboard

**Why good fit**
- Appeals to your optimisation instincts
- Tangible, measurable output

**Why not**
- Hard to define meaningful “entropy”
- May not drive behaviour change

**Revenue potential**
- Low → Medium

**Content potential**
- High

**Community potential**
- Medium
