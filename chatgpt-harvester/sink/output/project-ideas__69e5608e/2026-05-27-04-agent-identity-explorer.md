# 4. Agent Identity Explorer


## Problem Statement

Many organisations now deploy numerous agents.

Research suggests only a minority treat agents as independent identities. Shared credentials remain common. 

Security teams increasingly describe this as a major governance problem. 

## Approaches

### Approach A

Map:

- agents,
- permissions,
- credentials,
- ownership,
- capabilities.

### Approach B

Generate attack paths involving:

- delegated actions,
- tool permissions,
- privilege escalation opportunities.
