# 1. Agent Trust Ledger


## Problem Statement

Enterprises increasingly deploy dozens or hundreds of agents.

Most organisations cannot answer:

- Which agents are trustworthy?
- Which agents repeatedly make risky decisions?
- Which agents require supervision?

Current governance systems largely track permissions rather than behaviour. 

## Approaches

### Approach A

Build behavioural reputation systems.

Track:

- action success rates,
- rollback frequency,
- approval overrides,
- incident involvement.

### Approach B

Create trust decay models.

Trust changes over time based on:

- recency,
- environment,
- task category,
- observed outcomes.
