## 5. Sensitive Data Leak Pre-Checker


**Problem**  
Data leaks often occur because sensitive data is not detected before being sent to logs, APIs, or LLMs.

**Approaches**
- Scan outbound data for sensitive patterns  
- Block or redact risky content  
- Provide developer feedback  

**Tech hints**
- Regex + ML-based PII detection  
- Policy engine for enforcement  
- Integration with logging pipelines and API clients  

**Formats**
- SDK/middleware  
- CLI tool  
- CI/CD check  

**Why good fit**
- Strong security/privacy alignment  
- Immediate practical value  

**Why not**
- False positives/negatives  
- Performance overhead  

**Revenue potential**
- High  

**Content potential**
- High  

**Community potential**
- High
