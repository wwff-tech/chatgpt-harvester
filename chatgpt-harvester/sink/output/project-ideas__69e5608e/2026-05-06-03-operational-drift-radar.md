# 3. “Operational Drift Radar”


**Problem**  
Infrastructure, policy, prompts, workflows, and operational assumptions drift slowly until systems become brittle.

Most drift detection today focuses only on config state.

### Approaches
- Detect behavioural drift across systems
- Compare “expected operational patterns” vs reality
- Surface slow degradation trends

### Tech hints
- Embedding-based behavioural baselines
- Time-series anomaly detection
- Infrastructure graph comparison
- Prompt/version lineage

### Formats
- Drift dashboard
- CI/CD enforcement tool
- Kubernetes operator

### Why it is a good fit
- Drift is now everywhere:
  - infra,
  - AI systems,
  - human workflows,
  - security posture.
- Strong preventative value

### Why it is not a good fit
- Baseline modelling complexity
- False positive fatigue risk
