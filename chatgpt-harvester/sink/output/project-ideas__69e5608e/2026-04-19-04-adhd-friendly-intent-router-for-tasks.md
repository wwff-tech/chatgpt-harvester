## 4. ADHD-Friendly “Intent Router” for Tasks


**Problem**  
Task lists fail for ADHD — too static, too abstract, not context-aware.

**Approaches**
- Task → classified by energy level, time, context
- Real-time suggestion engine (“what should I do *now*?”)
- Feedback loop → learn actual behaviour vs planned

**Tech hints**
- Simple rules engine first
- Optional ML layer later
- SQLite + event log
- FastAPI backend + minimal UI

**Formats**
- CLI + web dashboard
- Telegram bot (fits your Rocky direction nicely)

**Why good fit**
- Direct personal relevance
- Combines your systems thinking + self-optimisation

**Why not**
- Crowded productivity space
- Requires behavioural nuance (hard problem)

**Revenue potential**
- Medium (niche but sticky)

**Content potential**
- Very high (personal + technical angle)

**Community potential**
- High in neurodivergent tech circles
