# 4. Permission Recovery Planner


**Problem**  
Security tooling increasingly removes permissions aggressively:
- emergency lockouts,
- broken production systems,
- difficult recovery processes.

Least-privilege systems often lack recoverability planning.

**Approaches**
- Model permission rollback paths  
- Simulate lockout scenarios  
- Generate recovery playbooks automatically  

**Tech hints**
- IAM graph analysis  
- Policy-as-code via Open Policy Agent  
- Cloud provider APIs  
- Privilege simulation  

**Formats**
- Security audit tool  
- IAM visualiser  
- CI/CD validation layer  

**Why good fit**
- Enterprise pain point  
- Security + operational crossover  

**Why not**
- Deep cloud integration requirements  
- Highly environment-specific
