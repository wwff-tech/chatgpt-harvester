# 6. “Attention Routing Engine”


**Problem**  
Humans and systems increasingly suffer from poor routing of attention:
- wrong alerts,
- wrong notifications,
- low-value interruptions,
- mistimed escalations.

### Approaches
- Dynamically prioritise interruptions
- Delay low-value notifications
- Route based on cognitive/system state

### Tech hints
- Priority scoring models
- Calendar + focus-state integration
- Alert suppression heuristics
- Reinforcement-learning-style adaptation

### Formats
- Desktop agent
- Notification proxy
- Slack/Teams middleware

### Why it is a good fit
- Huge modern pain point
- Bridges SRE + productivity domains
- Strong behavioural systems angle

### Why it is not a good fit
- Difficult trust problem
- Incorrect suppression could be costly
