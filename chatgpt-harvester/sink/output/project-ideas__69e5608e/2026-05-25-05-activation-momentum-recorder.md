# 5. Activation Momentum Recorder


## Problem Statement

ADHD productivity tooling focuses heavily on:

- tasks,
- schedules,
- reminders.

Current discussions increasingly emphasise:

- activation energy,
- task initiation,
- body doubling,
- transition friction. 

The real problem often occurs before work starts.

## Approaches

### Approach A

Record activation conditions:

- location,
- time,
- interruptions,
- environmental context.

Learn what predicts successful starts.

### Approach B

Generate personalised activation playbooks.

Recommend:

- body doubling,
- workspace changes,
- sequencing strategies.
