# 4. Permission Drift & Ownership Analyzer


**Problem**  
Permissions accumulate without clear ownership:
- orphaned access rights,  
- unclear responsibility for resources,  
- security risks.

**Approaches**
- Map permissions to owners  
- Detect orphaned or shared ownership  
- Suggest cleanup actions  

**Tech hints**
- IAM graph modelling  
- Integration with cloud providers  
- Policy analysis using Open Policy Agent  

**Formats**
- Security dashboard  
- CLI audit tool  
- Continuous monitoring service  

**Why good fit**
- Strong security relevance  
- High enterprise demand  

**Why not**
- Requires deep integration  
- Complex environments  

**Revenue potential**  
High  

**Content potential**  
High  

**Community potential**  
Medium
