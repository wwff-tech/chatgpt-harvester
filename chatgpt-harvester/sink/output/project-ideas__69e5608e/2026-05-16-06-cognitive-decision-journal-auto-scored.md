# 6. Cognitive Decision Journal (Auto-Scored)


**Problem**  
Humans rarely evaluate past decisions systematically, leading to repeated mistakes.

**Approaches**
- Record decisions with expected outcomes  
- Automatically prompt for outcome evaluation  
- Score decision accuracy over time  

**Tech hints**
- Structured journaling  
- Periodic review prompts  
- Local-first storage  

**Formats**
- Mobile/desktop app  
- CLI journaling tool  
- Weekly reports  

**Why good fit**
- Strong self-improvement angle  
- High personal value  

**Why not**
- Requires consistent usage  
- Subjective evaluation  

**Revenue potential**  
Medium  

**Content potential**  
Very high  

**Community potential**  
High
