# 4. Prompt Provenance System


## Problem Statement

Teams increasingly cannot answer:

- where prompts originated,
- who changed them,
- what behaviour changed,
- why performance shifted.

Prompt history is becoming operational history.

## Approaches

### Approach A

Git-like provenance for prompts.

Track:

- ownership,
- changes,
- behavioural impact.

### Approach B

Link prompts to:

- incidents,
- regressions,
- evaluation scores,
- deployment outcomes.

## Suggested Tech Hints

- semantic diffing
- vector similarity
- evaluation pipelines
- provenance metadata
- immutable audit logs

## Suggested Formats

- SaaS platform
- CLI tool
- AgentOps integration
- Prompt registry

## Why It Is A Good Fit

- Growing governance requirement
- Clear operational need
- Complements existing AI tooling

## Why It Is Not A Good Fit

- Market becoming crowded
- Requires workflow integration
