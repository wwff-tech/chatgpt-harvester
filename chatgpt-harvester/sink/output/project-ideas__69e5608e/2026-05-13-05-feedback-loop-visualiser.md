# 5. “Feedback Loop Visualiser”


**Problem**  
Systems contain hidden feedback loops (infra, agents, human processes) that are not visible or understood.

**Approaches**
- Map feedback loops explicitly  
- Visualise reinforcing vs balancing loops  
- Identify instability risks  

**Tech hints**
- Graph visualisation  
- Dependency mapping  
- Integration with observability stacks  

**Formats**
- Dashboard  
- Analysis tool  
- CLI visualiser  

**Why good fit**
- Cross-domain applicability  
- High explanatory power  

**Why not**
- Requires modelling effort  
- Potentially complex UI  

**Revenue potential**  
Medium → High  

**Content potential**  
Very high  

**Community potential**  
High
