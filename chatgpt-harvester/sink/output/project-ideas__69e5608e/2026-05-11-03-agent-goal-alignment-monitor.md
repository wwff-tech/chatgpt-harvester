# 3. Agent Goal Alignment Monitor


**Problem**  
Agents optimise subgoals that may conflict with overall objectives.

**Approaches**
- Track agent actions vs declared goals  
- Detect divergence patterns  
- Provide corrective signals  

**Tech hints**
- Goal representations (structured + embedding-based)  
- Action-to-goal similarity scoring  
- Integration with agent frameworks  

**Formats**
- Agent middleware  
- Monitoring dashboard  
- Evaluation tool  

**Why good fit**
- Directly addresses agent reliability concerns  
- High relevance in production AI  

**Why not**
- Goals are often ambiguous  
- Evaluation complexity  

**Revenue potential**  
High  

**Content potential**  
Very high  

**Community potential**  
High
