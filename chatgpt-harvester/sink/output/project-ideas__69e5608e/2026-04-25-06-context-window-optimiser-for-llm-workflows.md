## 6. Context Window Optimiser for LLM Workflows


**Problem**  
LLM context windows are limited and often filled inefficiently, reducing output quality.

**Approaches**
- Rank and prune context based on relevance
- Chunk and prioritise inputs
- Dynamic context shaping per task

**Tech hints**
- Embedding similarity ranking
- Token counting (tiktoken or equivalent)
- Heuristic + learned ranking

**Formats**
- Library
- CLI tool
- Middleware for agent frameworks

**Why good fit**
- Directly improves agent performance
- Practical and implementable

**Why not**
- Gains may be incremental
- Requires tuning per use case

**Revenue potential**
- Medium

**Content potential**
- High

- High
