# 5. Permission Coordination Monitor


**Problem**  
Security issues often arise from *misaligned permissions across systems*, not single misconfigurations.

**Approaches**
- Map permissions across interacting systems  
- Detect mismatches or unintended privilege escalation paths  
- Alert on risky coordination patterns  

**Tech hints**
- Graph-based permission modelling  
- IAM integration  
- Policy analysis  

**Formats**
- Security dashboard  
- CLI audit tool  
- Continuous monitoring service  

**Why good fit**
- Strong security/privacy relevance  
- Increasing complexity in cloud environments  

**Why not**
- Requires deep integration  
- High data complexity

High
