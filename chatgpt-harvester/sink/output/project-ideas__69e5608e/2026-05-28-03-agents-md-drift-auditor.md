# 3. AGENTS.md Drift Auditor


## Problem Statement

AGENTS.md adoption is accelerating rapidly across repositories and coding-agent ecosystems. 

However, instruction files increasingly drift away from:
- repository reality,
- team practices,
- infrastructure state,
- security expectations.

The result:
- brittle agents,
- unsafe assumptions,
- silent operational divergence.

## Approaches

### Approach A

Continuously compare AGENTS.md instructions against repository behaviour.

Detect:
- stale instructions,
- missing workflows,
- contradictory guidance.

### Approach B

Run synthetic agent tasks and compare expected vs actual behaviour.

## Suggested Tech Hints

- static analysis
- behavioural testing
- repository mining
- semantic diffing
- CI integration
