# 2. Runbook Drift Detector


## Problem Statement

Operational runbooks degrade silently.

In many organisations:

- systems change,
- dependencies evolve,
- infrastructure moves,

while documentation remains static.

AI agents amplify the problem because they consume outdated instructions literally. 

## Approaches

### Approach A

Compare runbooks against:

- deployments,
- telemetry,
- topology,
- infrastructure state.

### Approach B

Simulate incidents.

Measure whether runbooks still produce correct outcomes.

## Suggested Tech Hints

- Graph analysis
- OpenTelemetry
- Infrastructure-as-Code parsing
- CI validation
- Semantic diffing

## Suggested Formats

- GitHub Action
- Internal platform tool
- Incident management extension

## Why It Is A Good Fit

- Clear operational pain point
- Strong SRE relevance
- Easy to explain

## Why It Is Not A Good Fit

- Requires infrastructure visibility
- Validation complexity
