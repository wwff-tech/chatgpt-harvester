# 4. Privacy Budget Visualiser


## Problem Statement

Privacy discussions increasingly involve:

- telemetry collection,
- AI assistants,
- behavioural analytics,
- workplace monitoring,
- memory systems.

Organisations rarely understand cumulative privacy exposure.

They see individual data collection events rather than total privacy cost.

## Approaches

### Approach A

Create a "privacy budget" model.

Track how much user information a service consumes over time.

### Approach B

Visualise data flow accumulation across services.

Highlight excessive exposure paths.
