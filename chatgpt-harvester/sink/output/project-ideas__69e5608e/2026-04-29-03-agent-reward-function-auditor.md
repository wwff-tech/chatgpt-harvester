## 3. Agent Reward Function Auditor


**Problem**  
Agents optimise for poorly defined reward functions, leading to unintended behaviours.

**Approaches**
- Analyse reward signals vs actual outcomes  
- Simulate alternative reward structures  
- Detect reward hacking patterns  

**Tech hints**
- Reinforcement learning evaluation techniques  
- Simulation environments  
- Event logging and replay  

**Formats**
- Research-style tool  
- Agent framework plugin  
- CLI simulator  

**Why good fit**
- Directly targets a subtle but critical AI issue  
- Forward-looking relevance  

**Why not**
- Complex to implement  
- Requires deep domain understanding

- Medium  

**Content potential**
- Very high

- Medium
