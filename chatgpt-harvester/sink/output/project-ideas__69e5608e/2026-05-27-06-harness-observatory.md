# 6. Harness Observatory


## Problem Statement

Research increasingly indicates that harness design—not just model choice—determines agent effectiveness. 

Most organisations have little visibility into:

- harness evolution,
- middleware quality,
- memory effectiveness,
- tool-selection efficiency.

## Approaches

### Approach A

Observe harness components:

- prompts,
- middleware,
- memory,
- tool routing,
- execution environments.

Track their impact on outcomes.

### Approach B

Run continuous A/B experiments on harness changes.

Predict beneficial modifications.

## Suggested Tech Hints

- execution tracing
- experiment tracking
- replay systems
- telemetry pipelines
- statistical analysis

## Suggested Formats

- CI integration
