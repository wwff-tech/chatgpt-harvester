# 7. Leftfield: “Cultural Coordination Mapper”


**Problem**  
Organisations fail due to misalignment in:
- incentives,
- communication styles,
- expectations.

These are rarely mapped explicitly.

**Approaches**
- Analyse communication patterns  
- Identify coordination gaps  
- Visualise organisational alignment  

**Tech hints**
- Network analysis  
- NLP on communication metadata  
- Clustering algorithms  

**Formats**
- Dashboard  
- Org analysis tool  
- Research platform  

**Why good fit**
- High-level but impactful  
- Connects technical + organisational systems  

**Why not**
- Privacy concerns  
- Subjective interpretation  

**Revenue potential**  
Medium  

**Content potential**  
Very high  

**Community potential**  
Medium
