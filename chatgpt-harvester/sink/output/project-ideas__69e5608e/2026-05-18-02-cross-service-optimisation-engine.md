# 2. Cross-Service Optimisation Engine


**Problem**  
Optimisation is performed per service, not across the system:
- tuning one service harms others,  
- conflicting optimisations,  
- inefficient resource allocation.

**Approaches**
- Joint optimisation across services  
- Multi-objective optimisation (latency, cost, reliability)  
- Feedback loops between services  

**Tech hints**
- Constraint solvers  
- Multi-objective optimisation algorithms  
- Metrics ingestion via Prometheus  
- Reinforcement learning (optional advanced path)  

**Formats**
- Optimisation service  
- Dashboard  
- Auto-tuning system  

**Why good fit**
- High-value optimisation problem  
- Differentiated approach  

**Why not**
- Complex modelling  
- Hard to generalise  

**Revenue potential**  
High

High
