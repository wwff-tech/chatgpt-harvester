# 5. “Privacy Decision Auditor”


**Problem**  
Privacy-sensitive decisions (data sharing, logging, API calls) are implicit and hard to audit.

**Approaches**
- Log decisions involving sensitive data  
- Classify and flag risky decisions  
- Provide audit trails for compliance  

**Tech hints**
- PII detection + tagging  
- Decision logging layer  
- Integration with data pipelines  

**Formats**
- Compliance dashboard  
- CLI audit tool  
- API middleware  

**Why good fit**
- Strong regulatory pressure (GDPR, etc.)  
- High enterprise demand  

**Why not**
- False positives  
- Requires deep integration  

**Revenue potential**  
High  

**Content potential**  
High  

**Community potential**  
Medium
