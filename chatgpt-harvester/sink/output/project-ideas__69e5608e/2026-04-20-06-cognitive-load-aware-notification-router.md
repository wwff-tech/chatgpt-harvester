## 6. Cognitive Load-Aware Notification Router


**Problem**  
Notifications are delivered without regard to cognitive state — especially harmful for ADHD.

**Approaches**
- Context detection (time, activity, focus signals)
- Priority scoring + batching
- “Interruptibility model” (borrowed from HCI research)

**Tech hints**
- Python service + OS hooks
- Notification APIs (DBus, macOS, etc.)
- Simple ML model or rules engine

**Formats**
- Local daemon
- Mobile companion (later)
- Integration with Slack/email

**Why good fit**
- Direct personal relevance
- Systems + behavioural modelling crossover

**Why not**
- OS-level integration complexity
- Hard to get signal without invasive data

**Revenue potential**
- Medium

**Content potential**
- High

**Community potential**
- High in neurodivergent spaces

`notifications`, `adhd`, `focus`, `hci`
