## 7. Leftfield: “Micro-Habit Compiler” (Intent → Behaviour Loop)


**Problem**  
Self-improvement advice is abstract; translating intent into consistent behaviour is the real bottleneck.

**Approaches**
- Define habits as small executable “programs”
- Trigger system (time, context, state)
- Feedback loop with reinforcement

**Tech hints**
- Rules engine
- Event logging
- Optional reinforcement learning (later stage)

**Formats**
- CLI + mobile-friendly web UI
- Telegram bot
- Local-first app

**Why good fit**
- Systems thinking applied to behaviour
- Complements your interest in structured self-improvement

**Why not**
- Behavioural complexity is high
- Many existing habit trackers (but mostly shallow)

**Revenue potential**
- Medium

**Content potential**
- High

**Community potential**
- Medium
