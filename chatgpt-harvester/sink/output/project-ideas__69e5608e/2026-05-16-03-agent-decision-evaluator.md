# 3. Agent Decision Evaluator


**Problem**  
Agent decisions are rarely evaluated beyond immediate success:
- no long-term scoring,  
- no learning from past runs,  
- no optimisation of decision strategies.

**Approaches**
- Track decisions at each agent step  
- Evaluate against goals and outcomes  
- Optimise decision strategies over time  

**Tech hints**
- Structured traces  
- Reinforcement-style scoring  
- Integration with protocols like Model Context Protocol  
- Experiment tracking  

**Formats**
- Agent evaluation platform  
- Middleware  
- Dashboard  

**Why good fit**
- High relevance in agent ecosystems  
- Enables continuous improvement  

**Why not**
- Complex evaluation metrics  
- Requires large datasets  

**Revenue potential**  
High  

**Content potential**  
Very high  

**Community potential**  
High
