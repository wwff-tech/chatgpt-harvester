# 4. Security Usability Trade-off Visualiser


**Problem**  
Security improvements often degrade usability, but trade-offs are not explicitly modelled.

**Approaches**
- Quantify both security gain and usability cost  
- Visualise trade-offs  
- Suggest balanced configurations  

**Tech hints**
- Risk scoring models  
- UX friction metrics  
- Integration with Open Policy Agent  
- Data visualisation tools  

**Formats**
- Dashboard  
- Policy design tool  
- Audit report generator  

**Why good fit**
- Highly relevant for enterprise  
- Encourages balanced decision-making  

**Why not**
- Difficult to quantify usability  
- Subjective trade-offs  

**Revenue potential**  
High  

**Content potential**  
High  

**Community potential**  
Medium
