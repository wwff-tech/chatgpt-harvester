## 3. Agent Intent Verifier


**Problem**  
Agents may take actions that technically satisfy instructions but violate user intent.

**Approaches**
- Compare planned actions against high-level intent  
- Detect deviations or unintended consequences  
- Introduce approval checkpoints  

**Tech hints**
- Intent representation (structured goals)  
- Plan analysis + constraint checking  
- Secondary evaluation model  

**Formats**
- Agent middleware  
- CLI tool  
- IDE plugin for agent workflows  

**Why good fit**
- Directly addresses alignment issues  
- Growing need in agentic systems  

**Why not**
- Intent modelling is difficult  
- Risk of false positives  

**Revenue potential**
- High  

**Content potential**
- Very high  

**Community potential**
- High
