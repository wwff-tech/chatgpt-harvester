# 2. AGENTS.md Observatory


## Problem Statement

AGENTS.md appears to be becoming the closest thing to a shared agent-configuration standard. 

However, nobody currently has visibility into:

- adoption trends,
- common patterns,
- configuration quality,
- emerging best practices.

## Approaches

### Approach A

Continuously crawl public repositories.

Track:

- AGENTS.md usage,
- instruction patterns,
- subagent structures,
- workflow definitions.

### Approach B

Benchmark configurations against observed outcomes.

Produce quality scores and recommendations.

## Suggested Tech Hints

- GitHub mining
- embeddings
- static analysis
- data pipelines
- graph analytics

## Suggested Formats

- public dashboard
- newsletter
- developer tool
- research platform

## Why It Is A Good Fit

- Early ecosystem
- Strong content flywheel
- Open-source friendly

## Why It Is Not A Good Fit

- Monetisation less obvious
- Requires sustained data collection
