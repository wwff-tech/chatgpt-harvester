# 2. AGENTS.md Intelligence Platform


## Problem Statement

Repository-level agent configuration is rapidly becoming standardised.

Research examining thousands of repositories found AGENTS.md emerging as a common interoperability mechanism. 

Most organisations currently have no visibility into:

- instruction quality,
- conflicts,
- duplication,
- configuration drift,
- security implications.

## Approaches

### Approach A

Lint and analyse configuration quality.

Identify:

- contradictions,
- ambiguity,
- missing workflows,
- security concerns.

### Approach B

Simulate execution using synthetic tasks.

Measure likely compliance before deployment.

## Suggested Tech Hints

- static analysis
- prompt evaluation
- AST parsing
- policy engines
- repository mining

## Suggested Formats

- GitHub Action
- CLI tool
- VS Code extension
- SaaS governance dashboard

## Why It Is A Good Fit

- Emerging standard
- Strong developer audience
- Clear operational value

## Why It Is Not A Good Fit

- Configuration formats still evolving
- Ecosystem fragmentation
