# 4. Security Exception Half-Life Tracker


## Problem Statement

Security exceptions accumulate.

Nobody removes them.

Temporary becomes permanent.

Common examples:

- firewall exemptions,
- IAM exceptions,
- emergency production access,
- bypass policies.

## Approaches

### Approach A

Assign expiry and decay scores.

### Approach B

Treat exceptions as technical debt with interest.

Calculate organisational risk accumulation.

## Suggested Tech Hints

- IAM graph analysis
- policy-as-code

- risk models
