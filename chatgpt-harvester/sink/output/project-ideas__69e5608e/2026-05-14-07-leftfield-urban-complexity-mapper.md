# 7. Leftfield: “Urban Complexity Mapper”


**Problem**  
Cities accumulate complexity:
- infrastructure layers,  
- regulations,  
- transport systems.

This complexity is poorly visualised and understood.

**Approaches**
- Map urban systems and dependencies  
- Identify complexity hotspots  
- Suggest simplification opportunities  

**Tech hints**
- GIS data  
- Graph modelling  
- Public datasets  

**Formats**
- Interactive map  
- Research tool  
- Dashboard  

**Why good fit**
- Unique and exploratory  
- Cross-disciplinary appeal  

**Why not**
- Data availability issues  
- Hard to monetise  

**Revenue potential**  
Low → Medium  

**Content potential**  
Very high  

**Community potential**  
Medium

`urban`, `analysis`, `complexity`, `mapping`
