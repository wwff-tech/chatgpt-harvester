# 3. MCP Blast Radius Explorer


## Problem Statement

Security discussions increasingly focus on:

- MCP trust boundaries,
- tool permissions,
- prompt injection,
- over-privileged actions. 

Most teams know what tools agents have.

Few understand the consequences of those permissions.

## Approaches

### Approach A

Build permission graphs.

Map:

- tools,
- credentials,
- delegated authority,
- transitive access.

### Approach B

Run action simulations.

Estimate:

- affected systems,
- privilege escalation routes,
- recovery complexity.

## Suggested Tech Hints

- Attack graph modelling
- Capability graphs
- Policy engines
- SBOM-style inventories
- Graph databases

## Suggested Formats

- Security platform
- MCP gateway
- Governance dashboard

## Why It Is A Good Fit

- Immediate enterprise concern

- Emerging category
