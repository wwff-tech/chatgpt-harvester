## 3. Cross-Domain Alert Boundary Enforcer


**Problem**  
Alerts leak across teams and domains, causing confusion, duplication, and ownership ambiguity.

**Approaches**
- Define ownership boundaries for alerts  
- Route and isolate alerts per domain  
- Detect and resolve boundary violations  

**Tech hints**
- Tag-based routing  
- Integration with alerting systems (e.g., Prometheus, PagerDuty)  
- Policy-driven routing logic  

**Formats**
- Alerting middleware  
- CLI audit tool  
- Dashboard  

**Why good fit**
- Directly addresses alert fatigue and confusion  
- Practical in large organisations  

**Why not**
- Requires consistent tagging  
- Organisational buy-in needed  

**Revenue potential**
- Medium → High  

**Content potential**
- High  

**Community potential**
- Medium
