## 5. “Secure Prompt Gateway” (Input Validation for LLM Systems)


**Problem**  
Prompt injection and unsafe inputs are a growing attack vector in AI systems.

**Approaches**
- Input sanitisation and classification  
- Policy enforcement (block/transform risky prompts)  
- Context isolation  

**Tech hints**
- Pattern matching + ML classification  
- Sandboxing context segments  
- Rule engine for enforcement  

**Formats**
- API gateway  
- Middleware  
- SDK  

**Why good fit**
- Strong security + AI overlap  
- Timely and relevant  

**Why not**
- Arms race with attackers  
- False positives/negatives  

**Revenue potential**
- High  

**Content potential**
- Very high  

**Community potential**
- High

`security`, `llm`, `prompt-injection`, `ai`
