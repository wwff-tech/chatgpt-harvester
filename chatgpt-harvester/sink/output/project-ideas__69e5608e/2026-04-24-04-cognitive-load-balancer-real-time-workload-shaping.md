## 4. “Cognitive Load Balancer” (Real-Time Workload Shaping)


**Problem**  
Workloads are assigned without regard to current cognitive load, leading to burnout or inefficiency.

**Approaches**
- Track active tasks + interruptions
- Estimate current load score
- Dynamically suggest deferral, batching, or switching

**Tech hints**
- Local event tracking (apps, tasks)
- Heuristic scoring model
- Feedback loop for calibration

**Formats**
- Desktop agent
- CLI + dashboard
- Calendar integration

**Why good fit**
- Directly relevant to ADHD/ASD optimisation
- Extends prior ideas into *active intervention*

**Why not**
- Requires behavioural buy-in
- Risk of over-engineering personal workflows

**Revenue potential**
- Medium

**Content potential**
- Very high

**Community potential**
- High
