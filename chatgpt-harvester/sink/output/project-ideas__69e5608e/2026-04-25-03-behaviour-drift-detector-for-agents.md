## 3. Behaviour Drift Detector for Agents


**Problem**  
Agents change behaviour over time due to model updates, prompt tweaks, or environment changes, often without visibility.

**Approaches**
- Baseline behaviour profiles (input → output patterns)
- Detect deviations over time
- Alert on meaningful drift

**Tech hints**
- Event logging of agent interactions
- Embedding similarity for behaviour comparison
- Time-series analysis

**Formats**
- Monitoring service
- CLI report tool
- Dashboard

**Why good fit**
- Extends drift detection into agent domain
- Aligns with your interest in silent failure modes

**Why not**
- Requires sufficient data
- Defining “meaningful drift” is non-trivial

**Revenue potential**
- Medium

**Content potential**
- Very high

**Community potential**
- High
