# 3. Harness Diff Explorer


## Problem Statement

Research increasingly suggests:

> Harnesses matter as much as models.

Tool selection,
memory architecture,
execution policies,
middleware,
permission handling,

all significantly affect outcomes. 

Most teams lack visibility into harness evolution.

## Approaches

### Approach A

Track harness changes over time.

Measure:

- pass rates,
- latency,
- costs,
- tool usage,
- failure modes.

### Approach B

Compare multiple harness configurations against identical workloads.

Generate evidence-backed recommendations.
