## 4. “Task Friction Analyzer” (Why Tasks Stall)


**Problem**  
Tasks often stall not due to complexity, but due to hidden friction (context switching, unclear next steps, cognitive overload).

**Approaches**
- Track task lifecycle (start, pause, resume)
- Identify friction points (delays, switches)
- Suggest micro-optimisations

**Tech hints**
- Local event logging
- Time-series analysis
- Simple heuristic models

**Formats**
- CLI + daily report
- Local dashboard
- Integration with task tools

**Why good fit**
- Direct relevance to ADHD optimisation
- Focuses on *why* work stalls, not just tracking

**Why not**
- Requires consistent usage
- Signal extraction can be noisy

**Revenue potential**
- Low → Medium

**Content potential**
- Very high

**Community potential**
- High
