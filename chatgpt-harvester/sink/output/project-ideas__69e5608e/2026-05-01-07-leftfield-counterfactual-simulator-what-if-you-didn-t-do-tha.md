## 7. Leftfield: “Counterfactual Simulator” (What If You Didn’t Do That?)


**Problem**  
It is difficult to evaluate decisions because you only see the path taken, not alternatives.

**Approaches**
- Simulate alternative decisions  
- Compare outcomes probabilistically  
- Provide insight into decision quality  

**Tech hints**
- Monte Carlo simulation  
- Scenario modelling  
- Lightweight causal graphs  

**Formats**
- CLI tool  
- Notebook interface  
- Decision analysis dashboard  

**Why good fit**
- Deep systems-thinking alignment  
- Useful across domains  

**Why not**
- Requires assumptions  
- Computational complexity  

**Revenue potential**
- Medium  

**Content potential**
- Very high  

**Community potential**
- Medium
