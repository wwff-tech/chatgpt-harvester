## 7. Leftfield: “Digital Environment Simulator for Decisions”


**Problem**  
People make decisions (career, technical choices, purchases) without simulating long-term consequences.

**Approaches**
- Model decisions as inputs → simulate outcomes
- Use scenario trees with probabilities
- Allow iterative refinement

**Tech hints**
- Python + simulation frameworks
- Monte Carlo methods
- Simple UI for scenario definition

**Formats**
- CLI + visual output
- Web app
- Notebook-based tool

**Why good fit**
- Appeals to your thought-experiment style thinking
- Cross-domain applicability

**Why not**
- Garbage-in, garbage-out risk
- Hard to model real-world complexity

**Revenue potential**
- Low → Medium

**Content potential**
- High

**Community potential**
- Medium

`simulation`, `decision-making`, `modelling`, `analysis`
