# 5. Context Restart Assistant


## Problem Statement

A recurring ADHD/ASD complaint:

> Restarting work is often harder than doing the work.

Current tools optimise:

- task capture,
- reminders,
- scheduling.

Few optimise context reconstruction.

## Approaches

### Approach A

Periodic workspace snapshots:

- active files,
- browser tabs,
- notes,
- tickets,
- terminal sessions.

Generate resumable briefings.

### Approach B

Capture cognitive breadcrumbs:

- assumptions,
- next actions,
- unresolved questions.

Build restart packs automatically.

## Suggested Tech Hints

- local embeddings
- on-device inference
- activity indexing
- semantic search
- encrypted local storage

## Suggested Formats

- desktop utility
- browser extension
- Raycast plugin
- Obsidian integration

## Why It Is A Good Fit

- Strong ADHD relevance
- Privacy-first differentiation possible
- Useful for knowledge workers generally

## Why It Is Not A Good Fit

- Difficult signal extraction
