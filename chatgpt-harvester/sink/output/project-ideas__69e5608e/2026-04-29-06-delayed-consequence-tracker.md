## 6. Delayed Consequence Tracker


**Problem**  
Many actions have delayed effects, making it hard to link cause and outcome.

**Approaches**
- Track actions and long-term outcomes  
- Build causal timelines  
- Surface delayed correlations  

**Tech hints**
- Event logging with long retention  
- Time-lagged correlation analysis  
- Visual timeline tools  

**Formats**
- CLI + visual reports  
- Dashboard  
- Personal analytics tool  

**Why good fit**
- Cross-domain applicability  
- Aligns with systems thinking  

**Why not**
- Correlation ≠ causation  
- Requires long-term data  

**Revenue potential**
- Medium  

**Content potential**
- Very high  

**Community potential**
- Medium
