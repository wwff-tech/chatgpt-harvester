# 5. Narrative vs Reality Detector


**Problem**  
Systems (and organisations) maintain narratives (“everything is fine”, “we’re compliant”) that diverge from reality.

**Approaches**
- Compare reported metrics vs actual behaviour  
- Detect inconsistencies between dashboards and logs  
- Flag narrative drift  

**Tech hints**
- Data reconciliation  
- Statistical anomaly detection  
- NLP for narrative extraction  

**Formats**
- Dashboard overlay  
- Audit tool  
- Reporting system  

**Why good fit**
- Cross-domain relevance  
- Strong observability + governance angle  

**Why not**
- Requires access to multiple data sources  
- Interpretation challenges  

**Revenue potential**  
Medium → High  

**Content potential**  
Very high  

**Community potential**  
Medium

`observability`, `analysis`, `truth`, `metrics`
