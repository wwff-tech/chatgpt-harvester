# 3. Harness Observatory


## Problem Statement

Recent research increasingly indicates:

> agent harnesses matter as much as models.

Tool routing,
execution environments,
memory layers,
permissions,
workflow orchestration,

all affect outcomes dramatically. 

Yet almost nobody monitors harness quality.

## Approaches

### Approach A

Track harness performance:

- tool success rates,
- retries,
- latency,
- context efficiency.

### Approach B

Measure behavioural changes after harness updates.

Detect regressions automatically.

## Suggested Tech Hints

- execution tracing
- telemetry collection
- prompt provenance
- replay systems
- statistical evaluation
