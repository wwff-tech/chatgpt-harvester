# 7. Leftfield: Prediction Graveyard


## Problem Statement

Organisations make constant predictions:

- scaling forecasts,
- staffing plans,
- architectural assumptions,
- risk assessments,
- roadmap estimates.

Very few systematically track failed predictions.

Institutional learning is weak because wrong forecasts disappear.

## Approaches

### Approach A

Store predictions as first-class entities.

Track:

- confidence,
- evidence,
- outcomes,
- revisions.

### Approach B

Create organisational forecasting analytics.

Identify recurring bias patterns.

## Suggested Tech Hints

- Bayesian updating
- Temporal databases
- Confidence scoring
- Evidence graphs
- Forecast verification

## Suggested Formats

- Team retrospective platform
- Architecture governance tool
- Research notebook system
