## 6. “Task Context Rehydrator”


**Problem**  
When returning to a task, context is lost, increasing ramp-up time and cognitive load.

**Approaches**
- Capture task context snapshots  
- Rehydrate context on resume  
- Provide summaries and next steps  

**Tech hints**
- Markdown + structured metadata  
- LLM summarisation  
- Local-first storage  

**Formats**
- CLI tool  
- Editor plugin  
- Personal productivity app  

**Why good fit**
- Strong ADHD relevance  
- Immediate personal utility  

**Why not**
- Requires consistent usage  
- Context capture overhead  

**Revenue potential**
- Medium  

**Content potential**
- Very high  

**Community potential**
- High
