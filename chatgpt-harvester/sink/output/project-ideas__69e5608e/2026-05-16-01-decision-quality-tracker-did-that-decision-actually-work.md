# 1. “Decision Quality Tracker” (Did That Decision Actually Work?)


**Problem**  
Decisions are made, but rarely evaluated against outcomes in a structured way.

**Approaches**
- Record decisions with expected outcomes  
- Track real-world results  
- Score decision effectiveness over time  

**Tech hints**
- Event correlation (decision → outcome)  
- Time-series evaluation  
- Integration with observability via entity["software","OpenTelemetry","observability framework"]  
- Simple scoring models (success/failure, deviation from expectation)  

**Formats**
- CLI tool  
- Observability plugin  
- Lightweight dashboard  

**Why good fit**
- Cross-domain applicability  
- Enables continuous improvement  

**Why not**
- Attribution is hard (many variables affect outcomes)  
- Requires discipline in recording decisions  

**Revenue potential**  
High  

**Content potential**  
Very high  

**Community potential**  
High
