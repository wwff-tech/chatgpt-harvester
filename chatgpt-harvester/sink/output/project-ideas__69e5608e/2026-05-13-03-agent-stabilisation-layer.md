# 3. “Agent Stabilisation Layer”


**Problem**  
Agents over-adapt:
- excessive retries,  
- infinite loops,  
- unnecessary replanning.

**Approaches**
- Introduce stabilisation heuristics (retry caps, diminishing returns)  
- Detect behavioural instability patterns  
- Enforce convergence criteria  

**Tech hints**
- State tracking across agent runs  
- Heuristic scoring of progress vs churn  
- Integration with agent frameworks  
- Policy control via entity["software","Open Policy Agent","policy engine"]  

**Formats**
- Middleware SDK  
- Agent runtime plugin  
- Debugging dashboard  

**Why good fit**
- Directly addresses agent reliability  
- Increasing need in production AI  

**Why not**
- Hard to generalise  
- Risk of prematurely stopping valid exploration

High

Very high
