# 3. MCP Trust Explorer


## Problem Statement

MCP adoption is accelerating rapidly.

However:

- registry trust is unclear,
- tool provenance is weak,
- permission boundaries are inconsistent,
- supply-chain risks are growing. 

Most users cannot answer:

> Can I safely connect this tool to my agent?

## Approaches

### Approach A

Generate trust scores:

- maintainer reputation,
- update history,
- permission scope,
- security posture.

### Approach B

Create trust graphs showing:

- transitive dependencies,
- credential exposure paths,
- registry relationships.

## Suggested Tech Hints

- SBOM generation
- Trust graphs
- Static analysis
- Permission modelling
- Registry crawlers

## Suggested Formats

- Browser extension
- MCP registry explorer
- Enterprise governance dashboard

## Why It Is A Good Fit

- Timely
- Security-focused
- Growing ecosystem

## Why It Is Not A Good Fit

- Constant maintenance burden
- Requires ecosystem coverage
