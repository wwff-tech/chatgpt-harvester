# 5. “Local vs Global Alert Correlator”


**Problem**  
Alerts are generated locally without understanding system-wide context:
- alert storms,  
- misprioritisation,  
- missed root causes.

**Approaches**
- Correlate alerts across services  
- Identify root causes vs symptoms  
- Prioritise based on global impact  

**Tech hints**
- Event correlation  
- Graph clustering  
- Integration with entity["software","Prometheus","monitoring toolkit"]  
- Probabilistic inference  

**Formats**
- Alerting layer plugin  
- Dashboard  
- Incident response tool  

**Why good fit**
- Immediate SRE value  
- Reduces noise  

**Why not**
- Requires high-quality data  
- False correlations
