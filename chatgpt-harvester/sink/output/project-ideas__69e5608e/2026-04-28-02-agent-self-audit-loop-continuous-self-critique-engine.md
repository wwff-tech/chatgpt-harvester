## 2. “Agent Self-Audit Loop” (Continuous Self-Critique Engine)


**Problem**  
Agents execute tasks but rarely reflect on their own performance beyond immediate outputs.

**Approaches**
- Post-task self-evaluation (goal vs outcome)  
- Periodic retrospective analysis  
- Feedback loop into future behaviour  

**Tech hints**
- Structured evaluation schemas  
- Event logging + replay  
- Secondary evaluation models (local preferred)  

**Formats**
- Agent framework plugin  
- Middleware  
- CLI tool  

**Why good fit**
- Extends agent capability into self-improvement  
- Aligns with emerging agent architectures  

**Why not**
- Risk of reinforcing incorrect assumptions  
- Additional compute overhead  

**Revenue potential**
- Medium  

**Content potential**
- Very high  

**Community potential**
- High

`agents`, `self-evaluation`, `feedback-loop`, `ai`
