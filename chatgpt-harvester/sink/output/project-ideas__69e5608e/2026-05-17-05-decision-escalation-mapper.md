# 5. “Decision Escalation Mapper”


**Problem**  
Escalation paths in systems and organisations are unclear or inefficient.

**Approaches**
- Map escalation chains for decisions  
- Identify bottlenecks and dead ends  
- Optimise escalation flows  

**Tech hints**
- Graph modelling  
- Workflow analysis  
- Integration with incident tools  

**Formats**
- Dashboard  
- Analysis tool  
- Simulation engine  

**Why good fit**
- Cross-domain relevance  
- Improves operational efficiency  

**Why not**
- Requires organisational data  
- Dynamic environments

Medium → High  

**Content potential**  
High  

**Community potential**  
Medium
