# 1. “Assumption Registry” (Make the Invisible Explicit)


**Problem**  
Critical system assumptions (e.g., “this API is idempotent”, “latency < 200ms”) are undocumented and untracked.

**Approaches**
- Capture assumptions as first-class artefacts  
- Link assumptions to systems, services, and components  
- Enable querying and auditing  

**Tech hints**
- Schema for assumption metadata  
- Integration with observability tools like OpenTelemetry  
- Graph storage for relationships  
- Tagging + search  

**Formats**
- Internal developer platform module  
- CLI + web UI  
- Documentation plugin  

**Why good fit**
- Low-hanging but high-impact  
- Improves shared understanding  

**Why not**
- Requires cultural adoption  
- Risk of becoming stale  

**Revenue potential**  
Medium → High  

**Content potential**  
Very high  

**Community potential**  
High
