## 5. “Data Minimisation Enforcer” (Default to Less Data)


**Problem**  
Systems collect more data than necessary, increasing risk surface.

**Approaches**
- Analyse data collection points  
- Enforce minimal data schemas  
- Flag unnecessary fields  

**Tech hints**
- Schema analysis tools  
- Static + runtime checks  
- Policy-as-code  

**Formats**
- CI/CD check  
- API gateway plugin  
- CLI audit tool  

**Why good fit**
- Strong privacy/security alignment  
- Increasing regulatory importance  

**Why not**
- Hard to define “necessary” data  
- Potential pushback from teams  

**Revenue potential**
- High  

**Content potential**
- High  

**Community potential**
- Medium
