## 6. “Task Start Friction Analyser”


**Problem**  
The hardest part of work is often *starting*, especially for ADHD profiles.

**Approaches**
- Measure time between intention and task start  
- Identify friction sources  
- Suggest micro-interventions  

**Tech hints**
- Event tracking (intent vs action timestamps)  
- Behavioural pattern analysis  
- Lightweight recommendation engine  

**Formats**
- Desktop app  
- CLI tool  
- Browser extension  

**Why good fit**
- Strong behavioural insight  
- High personal relevance  

**Why not**
- Requires manual or semi-manual input  
- Subtle measurement challenges  

**Revenue potential**
- Medium  

**Content potential**
- Very high  

**Community potential**
- High

`adhd`, `motivation`, `behaviour`, `productivity`
