# 1. “Global Impact Analyzer” (What Does This Change Break Elsewhere?)


**Problem**  
Changes are evaluated locally (service, function, component), not system-wide.

**Approaches**
- Model dependencies across systems  
- Simulate ripple effects of changes  
- Score global impact vs local benefit  

**Tech hints**
- Service graph modelling  
- Integration with OpenTelemetry traces  
- Graph propagation algorithms  
- “what-if” simulation engine  

**Formats**
- CLI tool  
- Pre-deploy CI/CD check  
- Observability dashboard  

**Why good fit**
- Strong SRE relevance  
- Prevents cascading failures  

**Why not**
- Requires accurate dependency mapping  
- Computational complexity  

**Revenue potential**  
High  

**Content potential**  
Very high  

**Community potential**  
High

`systems`, `dependencies`, `analysis`, `sre`
