# 2. Autonomy Guardrail Engine


**Problem**  
Autonomous systems act beyond safe or intended limits because guardrails are static or insufficient.

**Approaches**
- Define dynamic “stop conditions”  
- Detect when systems exceed competence boundaries  
- Escalate or halt actions  

**Tech hints**
- Policy-as-code with Open Policy Agent  
- Runtime monitoring of behaviour vs expected patterns  
- Risk scoring models  

**Formats**
- Middleware layer  
- Agent runtime plugin  
- CI/CD enforcement tool  

**Why good fit**
- Strong alignment with AI safety concerns  
- Increasing regulatory relevance  

**Why not**
- Difficult to define competence boundaries  
- Risk of over-restricting systems  

**Revenue potential**  
High  

**Content potential**  
Very high  

**Community potential**  
High
