# 2. Auto-Remediation Accountability Layer


**Problem**  
Automated remediation systems act without clear traceability:
- who approved the automation,  
- what rules triggered it,  
- whether it was appropriate.

**Approaches**
- Attach accountability metadata to each automated action  
- Record decision context and triggering conditions  
- Enable review and rollback  

**Tech hints**
- Integration with SRE tooling (alerts, runbooks)  
- Policy-as-code via Open Policy Agent  
- Audit logging pipelines  

**Formats**
- Middleware layer  
- Incident analysis tool  
- CI/CD integration  

**Why good fit**
- Addresses real SRE risks  
- Improves trust in automation  

**Why not**
- Added complexity  
- Potential performance overhead
