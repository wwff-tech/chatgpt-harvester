## 2. “Retry Storm Simulator”


**Problem**  
Retries during partial outages amplify failures (classic cascading failure pattern).

**Approaches**
- Simulate retry behaviour under different failure scenarios  
- Model backoff strategies and their impact  
- Identify tipping points  

**Tech hints**
- Discrete event simulation  
- Configurable retry policies (exponential backoff, jitter)  
- Visual output for system load  

**Formats**
- CLI simulator  
- Notebook tool  
- SRE training utility  

**Why good fit**
- Highly relevant to real-world outages  
- Educational and practical  

**Why not**
- Requires accurate system modelling  
- Simulation complexity  

**Revenue potential**
- Medium  

**Content potential**
- Very high  

**Community potential**
- High
