# 4. Security Exception Decay Monitor


**Problem**  
Security exceptions (temporary allowances) become permanent, degrading security posture.

**Approaches**
- Track all exceptions with expiry and justification  
- Detect long-lived or unused exceptions  
- Enforce review cycles  

**Tech hints**
- Policy integration with Open Policy Agent  
- Time-based alerts  
- Usage tracking  

**Formats**
- Security dashboard  
- CI/CD policy check  
- Audit tool  

**Why good fit**
- Strong enterprise need  
- Direct security improvement  

**Why not**
- Requires integration with policy systems  
- Potential resistance from teams

High
