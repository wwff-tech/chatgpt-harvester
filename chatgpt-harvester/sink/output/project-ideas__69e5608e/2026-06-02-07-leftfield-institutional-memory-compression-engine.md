# 7. Leftfield: Institutional Memory Compression Engine


## Problem Statement

Organisations increasingly depend on:

- chat logs,
- tickets,
- incidents,
- documents,
- agent outputs.

Knowledge grows faster than humans can consume it.

The bottleneck becomes:

> preserving useful context without preserving everything.

This problem appears repeatedly in observability, agent memory, and organisational learning discussions. 

## Approaches

### Approach A

Build temporal memory layers.

Compress:

- decisions,
- assumptions,
- failures,
- outcomes.

### Approach B

Generate reusable organisational heuristics from historical activity.
