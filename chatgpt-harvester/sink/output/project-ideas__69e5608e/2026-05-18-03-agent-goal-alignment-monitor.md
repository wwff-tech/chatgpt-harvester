# 3. “Agent Goal Alignment Monitor”


**Problem**  
Agents optimise intermediate steps but drift from overall goals:
- local success, global failure,  
- inefficient execution paths,  
- unintended outcomes.

**Approaches**
- Track alignment between actions and high-level goals  
- Penalise locally optimal but globally suboptimal behaviour  
- Provide corrective feedback  

**Tech hints**
- Goal representation models  
- Step scoring vs goal alignment  
- Integration with entity["software","Model Context Protocol","AI interaction protocol"]  
- Trace analysis  

**Formats**
- Agent middleware  
- Evaluation dashboard  
- Training/feedback tool  

**Why good fit**
- Directly addresses agent reliability  
- Strong AI trend alignment  

**Why not**
- Hard to formalise goals  
- Evaluation complexity
