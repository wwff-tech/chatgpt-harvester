# 7. Leftfield: Assumption Expiry Engine


## Problem Statement

Most systems contain assumptions that were once correct:

- traffic patterns,
- user behaviour,
- retry intervals,
- approval chains,
- security constraints.

Nobody tracks when assumptions become invalid.

## Approaches

### Approach A

Convert assumptions into explicit machine-readable records.

Attach:

- evidence,
- owner,
- review date,
- confidence level.

### Approach B

Continuously evaluate assumptions against operational telemetry.

Alert when reality diverges.

## Suggested Tech Hints
