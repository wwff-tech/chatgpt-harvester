# 3. “Agent Prompt Minimiser”


**Problem**  
Agent systems accumulate:
- large prompts,  
- redundant instructions,  
- layered heuristics.

This increases cost, latency, and unpredictability.

**Approaches**
- Analyse prompt usage and effectiveness  
- Remove redundant or unused instructions  
- Optimise prompt structure  

**Tech hints**
- Token-level analysis  
- A/B testing of prompt variants  
- Integration with agent frameworks  
- Compatibility with entity["software","Model Context Protocol","AI interaction protocol"]  

**Formats**
- CLI tool  
- Agent debugging dashboard  
- Optimisation service  

**Why good fit**
- Immediate cost/performance impact  
- Strong AI relevance  

**Why not**
- Evaluation of prompt quality is subjective  
- Risk of degrading performance
