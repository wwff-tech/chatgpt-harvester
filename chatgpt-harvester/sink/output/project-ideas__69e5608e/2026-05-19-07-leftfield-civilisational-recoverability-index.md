# 7. Leftfield: “Civilisational Recoverability Index”


**Problem**  
Modern civilisation increasingly optimises:
- efficiency,
- interconnectedness,
- automation,

…while reducing:
- redundancy,
- graceful degradation,
- disaster recoverability.

**Approaches**
- Model societal/systemic recoverability  
- Track resilience indicators:
  - supply chains,
  - energy,
  - communications,
  - food systems.
- Simulate disruption recovery capability  

**Tech hints**
- System dynamics modelling  
- Public infrastructure datasets  
- Agent-based simulations  
- Graph resilience analysis  

**Formats**
- Research platform  
- Interactive simulation  
- Public dashboard  

**Why good fit**
- Deep systems-thinking appeal  
- Extremely strong intellectual/content angle  

**Why not**
- Hard monetisation path  
- Massive modelling complexity  

**Revenue potential**  
Low → Medium  

**Content potential**  
Extremely high  

**Community potential**  
Medium → High
