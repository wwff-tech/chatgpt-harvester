# 3. Trust Boundary Explorer for MCP


## Problem Statement

MCP adoption is growing rapidly, but security research continues to uncover weaknesses involving:

- tool trust,
- privilege boundaries,
- prompt injection,
- registry poisoning,
- unsafe execution paths. 

Most users cannot visualise MCP trust relationships.

## Approaches

### Approach A

Generate trust graphs.

Map:

- agents,
- tools,
- registries,
- credentials,
- permissions.

### Approach B

Run attack-path simulations.

Estimate:

- blast radius,
- privilege escalation routes,
- supply-chain risks.
