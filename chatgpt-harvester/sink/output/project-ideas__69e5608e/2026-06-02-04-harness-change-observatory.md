# 4. Harness Change Observatory


## Problem Statement

Recent research increasingly suggests harnesses matter more than prompts for long-running coding agents. 

Most teams cannot answer:

> Which harness change improved outcomes?

## Approaches

### Approach A

Track every harness modification.

Require predicted outcomes before deployment.

Compare prediction against reality.

### Approach B

Generate causal maps linking:

- middleware,
- tools,
- memory,
- prompts,
- execution environments.
