## 4. “Cognitive Load Budgeter”


**Problem**  
People exceed cognitive limits without awareness, leading to degraded decision-making and burnout.

**Approaches**
- Estimate cognitive load from task complexity + switching  
- Define daily “load budget”  
- Alert when nearing limits  

**Tech hints**
- Heuristic scoring model  
- Integration with task trackers  
- Time + context-switch tracking  

**Formats**
- Desktop app  
- CLI + reports  
- Calendar integration  

**Why good fit**
- Strong ADHD/ASD relevance  
- Quantifies an otherwise invisible constraint  

**Why not**
- Hard to model accurately  
- Requires behavioural buy-in  

**Revenue potential**
- Medium  

**Content potential**
- Very high  

**Community potential**
- High
