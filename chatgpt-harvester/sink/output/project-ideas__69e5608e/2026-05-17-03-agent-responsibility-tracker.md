# 3. Agent Responsibility Tracker


**Problem**  
Agent systems perform actions without clear responsibility boundaries:
- unclear ownership of outcomes,  
- difficulty assigning blame or credit,  
- weak auditability.

**Approaches**
- Assign responsibility at each agent step  
- Track delegation chains  
- Provide responsibility attribution for outcomes  

**Tech hints**
- Step-level metadata tracking  
- Integration with protocols like Model Context Protocol  
- Structured logs and trace correlation  

**Formats**
- Agent middleware  
- Debugging dashboard  
- Compliance tool  

**Why good fit**
- High relevance for enterprise AI  
- Supports governance and compliance  

**Why not**
- Hard to define responsibility in complex flows  
- Potential overhead

High

Very high
