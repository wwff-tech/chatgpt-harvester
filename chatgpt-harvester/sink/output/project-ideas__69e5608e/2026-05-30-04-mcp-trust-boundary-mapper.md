# 4. MCP Trust Boundary Mapper


## Problem Statement

Security research increasingly suggests that MCP adoption is outpacing security maturity. 

Organisations struggle to understand:

- trust boundaries,
- tool provenance,
- transitive permissions,
- tool-chain risks.

## Approaches

### Approach A

Automatically map trust boundaries across:

- agents,
- tools,
- credentials,
- registries.

### Approach B

Generate risk scores based on:

- privilege exposure,
- provenance,
- registry trust,
- tool behaviour.
