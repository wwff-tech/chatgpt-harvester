## 2. Justification Diff Engine


**Problem**  
Two identical outputs can be produced for *different reasons*, and changes in reasoning go unnoticed.

**Approaches**
- Capture reasoning traces (structured or inferred)  
- Diff reasoning between runs  
- Highlight shifts in logic or assumptions  

**Tech hints**
- Structured reasoning schema  
- Text diff + semantic diff (embeddings)  
- Versioned storage  

**Formats**
- CLI tool  
- CI regression checker  
- Agent debugging plugin  

**Why good fit**
- Targets subtle AI/system regressions  
- Strong complement to testing  

**Why not**
- Reasoning capture is imperfect  
- Noise vs signal challenge  

**Revenue potential**
- Medium  

**Content potential**
- Very high  

**Community potential**
- Medium → High

`reasoning`, `diff`, `ai`, `debugging`
