# 2. AGENTS.md Quality Auditor


## Problem Statement

Repository-level agent configuration is becoming standard.

However:

- instructions rot,
- conflicting guidance accumulates,
- agent behaviours diverge.

Research shows AGENTS.md-style configuration is rapidly becoming the dominant configuration mechanism across repositories. 

## Approaches

### Approach A

Lint configuration quality:

- contradictions,
- ambiguity,
- missing workflows,
- missing security controls.

### Approach B

Simulate agent execution against instructions.

Measure compliance rates.

## Suggested Tech Hints

- static analysis
- prompt evaluation
- policy engines
- repository scanners
- synthetic agent testing

## Suggested Formats

- CLI
- GitHub Action
- VSCode extension
- SaaS governance dashboard

## Why It Is a Good Fit

- New ecosystem

## Why It Is Not a Good Fit
