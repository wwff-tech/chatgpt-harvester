# 5. “State Drift Replay System”


**Problem**  
Distributed systems fail because:
- hidden state drifts accumulate,
- changes are difficult to reconstruct,
- debugging historical system evolution is painful.

**Approaches**
- Record state transitions continuously  
- Replay system evolution over time  
- Diff expected vs actual drift progression  

**Tech hints**
- Event sourcing  
- Immutable append-only logs  
- Distributed tracing  
- Snapshotting  
- Time-travel debugging concepts  

**Formats**
- Infra debugging platform  
- K8s operator  
- Incident investigation tool  

**Why good fit**
- Strong debugging and reliability value  
- Highly technical and differentiated  

**Why not**
- Storage-heavy  
- Significant engineering complexity

High
