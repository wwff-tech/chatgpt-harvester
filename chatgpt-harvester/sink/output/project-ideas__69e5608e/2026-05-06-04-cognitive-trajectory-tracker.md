# 4. Cognitive Trajectory Tracker


**Problem**  
Humans do not merely lose focus — they drift cognitively over sequences of interruptions and context switches.

This is particularly relevant for ADHD/ASD profiles.

### Approaches
- Track interruption chains
- Model energy/focus decay trajectories
- Predict “task abandonment probability”

### Tech hints
- Local-first telemetry
- Context-switch detection
- Time-series behavioural modelling
- Optional wearable integration

### Formats
- Desktop app
- CLI + markdown reports
- Obsidian plugin

### Why it is a good fit
- Highly differentiated
- Strong neurodivergent relevance
- Connects systems thinking with cognition

### Why it is not a good fit
- Behaviour modelling is noisy
- User compliance burden
