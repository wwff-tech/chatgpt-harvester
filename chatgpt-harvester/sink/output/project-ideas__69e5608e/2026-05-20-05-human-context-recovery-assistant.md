# 5. “Human Context Recovery Assistant”


## Problem
Knowledge workers increasingly suffer from:
- interruption fragmentation,
- tab overload,
- context switching,
- memory discontinuity.

Particularly severe for ADHD/ASD profiles. citeturn0search3turn0search12turn0search16

Most productivity systems optimise:
- task throughput,
- scheduling,
- reminders.

Very few optimise:
> “How fast can you recover context after interruption?”

## Approaches
- Snapshot work context periodically  
- Build resumable “attention checkpoints”  
- Generate restart summaries automatically  

## Suggested tech hints
- Window/app activity capture  
- Local-first indexing  
- Semantic workspace snapshots  
- Context reconstruction via embeddings  
- Privacy-preserving on-device models  

## Suggested formats
- Desktop companion app  
- Browser extension  
- macOS/Linux menu bar utility  

## Why it is a good fit
- Huge unmet neurodivergent tooling gap  
- Strong digital minimalism overlap  
- Privacy-first angle differentiates it  

## Why it is not a good fit
- Privacy sensitivity is extremely high  
- Capturing enough context without surveillance creep is difficult
