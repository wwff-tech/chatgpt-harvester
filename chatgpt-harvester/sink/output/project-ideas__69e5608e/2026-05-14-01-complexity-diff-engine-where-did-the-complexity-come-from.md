# 1. “Complexity Diff Engine” (Where Did the Complexity Come From?)


**Problem**  
Systems become complex gradually, but there’s no clear view of *how complexity has increased over time*.

**Approaches**
- Track structural complexity metrics (dependencies, rules, configs)  
- Diff complexity over time  
- Highlight sources of growth  

**Tech hints**
- Graph complexity metrics (node/edge growth, centrality)  
- Integration with entity["software","OpenTelemetry","observability framework"] traces  
- Versioned snapshots  
- Time-series analysis  

**Formats**
- CLI analyser  
- Dashboard  
- CI/CD report  

**Why good fit**
- Makes invisible complexity visible  
- Cross-domain applicability  

**Why not**
- Defining “complexity” precisely is non-trivial  
- May produce noisy signals

Very high
