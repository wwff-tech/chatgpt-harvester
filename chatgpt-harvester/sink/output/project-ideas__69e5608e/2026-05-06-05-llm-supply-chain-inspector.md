# 5. “LLM Supply Chain Inspector”


**Problem**  
AI systems increasingly depend on:
- prompts,
- models,
- retrieval corpora,
- plugins,
- MCP servers,
- agent frameworks.

The supply chain is becoming opaque and risky.

### Approaches
- Generate dependency graphs for AI systems
- Score risk/exposure
- Detect hidden third-party dependencies

### Tech hints
- SBOM-inspired approach for AI
- Dependency graphing
- Prompt lineage tracking
- API discovery

### Formats
- CLI auditor
- CI/CD scanner
- Governance dashboard

### Why it is a good fit
- Strong security relevance
- AI governance demand increasing rapidly
- Emerging market category

### Why it is not a good fit
- Rapidly evolving standards
- Vendor integration complexity
