# 4. Secret Exposure Simulator


## Problem Statement

Agent systems increasingly hold:

- API keys,
- customer data,
- cloud credentials,
- internal documents.

Most organisations have little visibility into how secrets could propagate through multi-agent workflows. 

## Approaches

### Approach A

Simulate compromise scenarios.

Track secret propagation paths.

### Approach B

Model credential exposure across:

- memory systems,
- tool chains,
- delegated agents,
- logs.
