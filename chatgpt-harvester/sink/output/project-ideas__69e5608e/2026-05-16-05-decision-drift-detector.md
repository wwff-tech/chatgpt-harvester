# 5. Decision Drift Detector


**Problem**  
Decisions that were once optimal become suboptimal due to changing conditions.

**Approaches**
- Monitor performance of decisions over time  
- Detect degradation trends  
- Trigger re-evaluation  

**Tech hints**
- Time-series analysis  
- Baseline comparison  
- Integration with Prometheus  
- Statistical drift detection  

**Formats**
- Monitoring plugin  
- Dashboard  
- Alerting system  

**Why good fit**
- Practical and measurable  
- Works across domains  

**Why not**
- Requires historical data  
- False positives possible
