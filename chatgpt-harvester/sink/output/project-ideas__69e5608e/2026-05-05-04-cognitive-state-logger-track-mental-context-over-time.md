## 4. “Cognitive State Logger” (Track Mental Context Over Time)


**Problem**  
Humans lose track of mental context (focus, energy, intent), especially across interruptions.

**Approaches**
- Log cognitive state snapshots (manual + inferred)  
- Reconstruct context when resuming tasks  
- Identify patterns over time  

**Tech hints**
- Lightweight journaling + tagging  
- Time-based context reconstruction  
- Optional biometric/device signals  

**Formats**
- Desktop/mobile app  
- CLI + markdown logs  
- Weekly reports  

**Why good fit**
- Strong ADHD/ASD relevance  
- Bridges human and system observability  

**Why not**
- Requires user input  
- Subjective data  

**Revenue potential**
- Medium  

**Content potential**
- Very high  

**Community potential**
- High
