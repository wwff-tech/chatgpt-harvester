## 4. “Focus Debt Tracker” (Accumulated Cognitive Burden)


**Problem**  
Unfinished tasks and interruptions accumulate as “focus debt”, reducing effectiveness over time.

**Approaches**
- Track incomplete tasks + context switches
- Model accumulation and decay of focus debt
- Suggest resets (breaks, task closures)

**Tech hints**
- Local tracking daemon
- Time-series analysis
- Simple decay model

**Formats**
- Desktop widget
- CLI + reports
- Integration with task managers

**Why good fit**
- Extends ADHD-related tooling into a novel metric
- Quantifies a real but intangible issue

**Why not**
- Abstract concept may be hard to validate
- Behavioural adoption required

**Revenue potential**
- Low → Medium

**Content potential**
- Very high

**Community potential**
- High
