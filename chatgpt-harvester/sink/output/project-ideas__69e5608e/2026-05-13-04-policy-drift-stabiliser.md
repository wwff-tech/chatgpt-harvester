# 4. “Policy Drift Stabiliser”


**Problem**  
Security and compliance policies change over time, often creating instability:
- conflicting updates,  
- oscillating rules,  
- reactive tightening/loosening.

**Approaches**
- Track policy evolution over time  
- Detect drift patterns and instability  
- Suggest stabilisation strategies  

**Tech hints**
- Policy diffing  
- Time-series analysis  
- Integration with entity["software","Open Policy Agent","policy engine"]  
- Graph-based policy modelling  

**Formats**
- Security dashboard  
- CI/CD check  
- Audit tool  

**Why good fit**
- Strong security relevance  
- Increasing policy complexity  

**Why not**
- Requires full visibility  
- Complex interactions
