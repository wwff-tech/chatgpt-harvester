# 4. Trust Boundary Drift Detector


**Problem**  
Security models assume stable trust boundaries (internal vs external, trusted services), but architectures evolve.

**Approaches**
- Map trust boundaries explicitly  
- Detect drift as systems change  
- Alert on risky boundary violations  

**Tech hints**
- Network and service graph modelling  
- IAM and policy integration  
- Zero-trust frameworks  
- Graph anomaly detection  

**Formats**
- Security dashboard  
- Continuous audit tool  
- CLI scanner  

**Why good fit**
- High relevance in cloud-native systems  
- Aligns with zero-trust trends  

**Why not**
- Requires deep system visibility  
- Complex modelling

High

High

Medium
