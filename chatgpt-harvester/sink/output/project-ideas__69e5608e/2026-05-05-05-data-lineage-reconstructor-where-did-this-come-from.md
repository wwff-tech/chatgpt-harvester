## 5. “Data Lineage Reconstructor” (Where Did This Come From?)


**Problem**  
Data flows across systems without clear lineage, making debugging and compliance difficult.

**Approaches**
- Track data transformations across pipelines  
- Reconstruct lineage graphs  
- Provide queryable provenance  

**Tech hints**
- Metadata tracking  
- Graph databases  
- Integration with pipelines (Airflow, dbt)  

**Formats**
- Dashboard  
- CLI query tool  
- Data pipeline plugin  

**Why good fit**
- Strong data engineering + compliance relevance  
- High enterprise demand  

**Why not**
- Requires deep integration  
- Performance overhead  

**Revenue potential**
- High  

**Content potential**
- High  

**Community potential**
- Medium
