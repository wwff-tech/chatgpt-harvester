# 4. AGENTS.md Compliance Engine


## Problem Statement

AGENTS.md has become a de facto interoperability standard for coding agents. 

Most repositories now treat it as documentation.

Few treat it as enforceable policy.

## Approaches

### Approach A

Convert AGENTS.md into executable constraints.

Verify agent actions against declared rules.

### Approach B

Generate compliance reports:

- rule violations,
- drift,
- coverage gaps,
- outdated instructions.

## Suggested Tech Hints

- Static analysis
- AST inspection
- Policy-as-code
- Repository mining
- CI/CD integration

## Suggested Formats

- GitHub Action
- CLI utility
- VS Code extension
- SaaS platform

## Why It Is A Good Fit

- Riding a growing standard
- Developer-native
- Open-source friendly

## Why It Is Not A Good Fit

- Standard still evolving
- Limited enterprise urgency today
