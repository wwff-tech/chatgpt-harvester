# 3. Agent Assumption Monitor


**Problem**  
Agents implicitly assume:
- tool success,  
- data freshness,  
- execution correctness.

These assumptions often fail silently.

**Approaches**
- Track assumptions per agent step  
- Detect mismatches between expectation and reality  
- Trigger retries, fallbacks, or escalation  

**Tech hints**
- Step-level metadata tracking  
- Integration with agent protocols like Model Context Protocol  
- Heuristic or probabilistic validation  
- Structured trace logs  

**Formats**
- Agent middleware  
- Debugging dashboard  
- Evaluation framework  

**Why good fit**
- Strong alignment with agent reliability needs  
- Increasing production relevance  

**Why not**
- Adds overhead  
- Hard to enumerate all assumptions
