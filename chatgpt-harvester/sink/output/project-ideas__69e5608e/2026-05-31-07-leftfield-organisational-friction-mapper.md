# 7. Leftfield: Organisational Friction Mapper


## Problem Statement

Most organisations optimise throughput.

Very few optimise:

> Where should friction intentionally exist?

Examples:

- approvals,
- reviews,
- planning,
- documentation,
- security checks.

The result is usually:

- unnecessary bureaucracy,
- hidden risk,
- operational drag.

## Approaches

### Approach A

Map friction across workflows.

Identify:

- useful friction,
- accidental friction,
- missing friction.

### Approach B

Run simulations:

- remove friction,
- add friction,
- shift friction.

Estimate outcome changes.
