# 2. Action Surface Inventory


## Problem Statement

Most organisations know:

- their services,
- their repositories,
- their infrastructure.

They increasingly do **not** know:

- which agents can take action,
- which systems they can modify,
- which credentials they possess.

Action-capable agent tools now dominate usage growth. 

## Approaches

### Approach A

Discover and classify every action pathway:

- GitHub writes,
- ticket creation,
- cloud changes,
- deployments,
- communications.

### Approach B

Build attack graphs around agent actions.

Highlight:

- privilege escalation,
- blast radius,
- credential concentration.
