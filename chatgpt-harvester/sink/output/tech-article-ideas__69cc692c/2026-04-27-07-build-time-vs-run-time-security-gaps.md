## 7) Build-Time vs Run-Time Security Gaps


- **Title:** *Your Secure Build Doesn’t Mean a Secure Runtime*  
- **Summary:** Systems that pass security checks at build time can still be vulnerable due to runtime configuration, environment drift, or dynamic behaviour.  
- **Angle:** “Security is temporal” — guarantees degrade after deployment.  
- **Matches Interests:** Security, DevOps, SRE  
- **Format:** **Long form**

- **Suggested Points to Cover:**
  - Build-time scanning limitations  
  - Runtime attack surfaces  
  - Drift and configuration risks

  - Continuous verification strategies
